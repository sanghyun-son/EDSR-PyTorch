# Lightweight EDSR with Semantic Guidance for Remote Sensing Images

Super-resolution experiments on the UC Merced Land Use dataset at ×2, ×3 and ×4. The project compares three models:

| Model | Residual blocks | Feature channels | Training loss |
|---|---|---|---|
| **EDSR** | 16 | 64 | L1 |
| **LW-EDSR** | 8 | 32 | L1 |
| **LW-EDSR-SL** | 8 | 32 | L1 + semantic feature loss (frozen ResNet-18) |

Reconstruction quality is measured with PSNR and SSIM. Downstream usefulness is measured by classifying the super-resolved test images with a single frozen ResNet-18 (accuracy and macro-F1).

## Branches

- **`main`**: the experiments described in this README (EDSR, LW-EDSR, LW-EDSR-SL).
- **dev branch (channel attention)**: a separate dev branch for adding channel attention to LW-EDSR is under development by **Jonas**. It is work in progress and not yet part of the results reported here.

## Pipeline overview

Run the steps in this order:

1. Download and prepare the data
2. (Optional) generate bicubic baseline images
3. Train EDSR (×2, ×3, ×4)
4. Train LW-EDSR (×2, ×3, ×4)
5. Train ResNet-18 (needed for the semantic loss and for classification)
6. Train LW-EDSR-SL (×2, ×3, ×4)
7. Classify all reconstructed images

> The ResNet-18 weights **must** exist before training LW-EDSR-SL.

## 1. Download and prepare data

```bash
python3 prepare_LR_data.py
```

Downloads UC Merced from Hugging Face, makes a stratified 70/10/20 train/val/test split (seed 42), and creates the paired HR/LR images. The same source images are in the same split at every scale.

| Folder | Contents |
|---|---|
| `x1/` | 256×256 HR images (targets for ×2 and ×4) |
| `x2/` | 128×128 LR inputs |
| `x3/` | 85×85 LR inputs |
| `x3_hr/` | 255×255 HR targets for ×3 (top-left crop of `x1`) |
| `x4/` | 64×64 LR inputs |

Each folder is organized as `<folder>/{train,val,test}/<class>/*.png`. LR images are generated by bicubic downsampling of the matching HR image. Split information is saved in `split_manifest.csv` and class indices in `class_to_idx.json`.

Pass `--overwrite` to rebuild existing folders.

## 2. Generate bicubic baseline data

```bash
python3 prepare_bicubic_data.py
```

Creates the bicubic-upsampled images used as the non-learned baseline.

## 3. Train EDSR

```bash
# ×2
python train_edsr_x2_ucmerced.py --data-dir data/edsr_data --seed 42 --batch-size 4 --epochs 100 --patience 15

# ×3
python train_edsr_x3_ucmerced.py --data-dir data/edsr_data --seed 42 --batch-size 4 --epochs 100 --patience 15

# ×4
python train_edsr_x4_ucmerced.py --data-dir data/edsr_data --seed 42 --batch-size 4 --epochs 100 --patience 15
```

## 4. Train LW-EDSR (without semantic loss)

```bash
# ×2
python train_light_weight_ucmerced.py --scale 2 --data-dir data/edsr_data --seed 42 --batch-size 4 --epochs 100 --patience 15

# ×3
python train_light_weight_ucmerced.py --scale 3 --data-dir data/edsr_data --seed 42 --batch-size 4 --epochs 100 --patience 15

# ×4
python train_light_weight_ucmerced.py --scale 4 --data-dir data/edsr_data --seed 42 --batch-size 4 --epochs 100 --patience 15
```

## 5. Train ResNet-18 (for the semantic loss and classification)

```bash
python3 train_resnet18_x1_ucmerced.py
```

Trains a ResNet-18 classifier on the original-resolution UC Merced images. The best weights are saved to `weights/resnet18_ucmerced_x1_best.pth`. This network is used in two ways:

- as the frozen feature extractor (`layer3`) for the semantic loss, and
- as the fixed classifier in the final evaluation.

## 6. Train LW-EDSR-SL (with semantic loss)

Requires the ResNet-18 weights from step 5.

```bash
# ×2
python train_light_weight_ucmerced.py --scale 2 --seed 42 --data-dir data/edsr_data --epochs 100 --batch-size 4 --semantic-loss --semantic-weights weights/resnet18_ucmerced_x1_best.pth

# ×3
python train_light_weight_ucmerced.py --scale 3 --seed 42 --data-dir data/edsr_data --epochs 100 --batch-size 4 --semantic-loss --semantic-weights weights/resnet18_ucmerced_x1_best.pth

# ×4
python train_light_weight_ucmerced.py --scale 4 --seed 42 --data-dir data/edsr_data --epochs 100 --batch-size 4 --semantic-loss --semantic-weights weights/resnet18_ucmerced_x1_best.pth
```

## 7. Classify the reconstructed images

```bash
python3 evaluate_sr_classification.py
```

Runs the trained ResNet-18 on the images produced by EDSR, LW-EDSR and LW-EDSR-SL (and the bicubic baseline) and reports accuracy and macro-F1.

## Default training settings

| Setting | Value |
|---|---|
| Optimizer | Adam |
| Learning rate | 1e-4 |
| Batch size | 4 |
| Max epochs | 100 |
| Early-stopping patience | 15 epochs |
| Seed | 42 (paper also uses 123 and 999) |
| Semantic-loss weight | 50 |
| Semantic feature layer | ResNet-18 `layer3` |

To reproduce the three-seed results, repeat the training commands with `--seed 123` and `--seed 999`.

## Notes

- The ×3 experiments use 255×255 HR targets (`x3_hr`) so that the HR size is divisible by 3. ×2 and ×4 use 256×256 targets.
- Results (PSNR, SSIM, accuracy) are only comparable within the same scale.
- Epoch times depend on the hardware (experiments were run on an Apple M5 with the PyTorch MPS backend).
